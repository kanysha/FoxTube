и разрешённое SSH-соединение из текущей сессии.

## Что работает — исходная принятая версия

- Python 3.12/FastAPI, PostgreSQL 17, SQLAlchemy/psycopg, пять линейных миграций
  Alembic до `0005_moderation`. Nginx, API, PostgreSQL и Python-worker —
  четыре постоянных сервиса. Redis/Celery/HLS/SPA не добавлялись.
- Регистрация атомарно создаёт пользователя, канал и сессию. Вход/выход,
  Argon2id, непрозрачные серверные сессии, отзыв/ротация, CSRF/Origin,
  общие ограничения попыток и тела JSON. Swagger `/docs` использует общую сессию.
- Главная, поиск по названию, загрузка с прогрессом, студия, просмотр и настройки
  владельца. Канал `/channels/{id}` и короткий `/@handle`, видео и плейлисты
  автора, подписка. Фронт — Jinja2/CSS/vanilla JavaScript; логотип с лисой.
- Потоковая загрузка → PostgreSQL-очередь с арендой → FFmpeg/ffprobe → MP4
  H.264/AAC до 720p и JPEG. HTML5-плеер с собственными controls и логотипом,
  перемоткой/звуком/fullscreen; без JavaScript остаются нативные controls.
  READY выставляется только после проверки и публикации текущей попытки.
- Индикаторы из пользовательского архива сопровождают навигацию, запросы,
  загрузку/обработку и буферизацию. При сокращении движения используются PNG.
  Наведение на миниатюру после 350 мс запускает первые 20% по кругу без звука;
  один активный предпросмотр, прежний защищённый MP4 URL, без новых файлов/сервисов.
  Уход выгружает video; reduced motion/Save-Data отключают autoplay.
- Карточки приближены к YouTube: миниатюра 16:9 с длительностью, аватар рядом
  с названием, компактные метаданные; при предпросмотре значок mute и тонкая
  красная полоса позиции. Центральный Play — только исходный логотип сайта,
  без дополнительной стрелки/подложки, с естественными пропорциями.
- Приватные видео и grant по точному email, отзыв, редактирование и удаление
  владельцем. Один ACL для списков, счётчиков, HTML, API, превью, MP4, HEAD/Range.
  Раздаёт Nginx через internal location; прямой публичный путь к тому закрыт.
- Настоящие лайки, комментарии с удалением, подписки и их лента,
  публичные/приватные плейлисты. Состояние сохраняется в PostgreSQL.
  Списки и счётчики исключают недоступное до пагинации; плейлист не меняет ACL ролика.
- Жалобы, очереди открытых/закрытых обращений, скрытие/восстановление видео
  и решение с причиной. Admin ищет аккаунт по точному email/ID, назначает роли
  и читает аудит. Роли не открывают приватные медиа. Последнего admin понизить нельзя.
- Первое назначение admin — привилегированная CLI-команда для уже существующего
  аккаунта, только пока admin нет. Нет стандартного пароля и HTTP bootstrap.
  Модерация/роли/аудит атомарны в ограниченных PostgreSQL-функциях;
  API не получает прямого UPDATE защищённых столбцов или журнала.
- `bash scripts/bootstrap.sh --demo` / `bash scripts/demo.sh`: 6 аккаунтов,
  12 шестисекундных MP4 через обычный API и worker, 6 комментариев,
  6 плейлистов, подписки, разрешения и жалоба. Видео — синтетический сигнал,
  не съёмка с камеры. Пароли случайные в локальном manifest с правами 0600.
  Повтор использует сохранённые IDs; удалённый вручную комментарий не воссоздаётся.
- Ограничения загрузок, квот, очереди, времени/ресурсов FFmpeg, повторы,
  очистка и защита от устаревшей попытки. Worker не меняет private/hidden/deleted.
  Настроенные лимиты не означают измеренную ёмкость сервера.
- Ограниченные роли БД API/worker, read-only контейнеры, постоянные тома,
  health/readiness, повторный bootstrap с сохранением настроек и данных.
  Четыре проектных профиля агентов и четыре навыка.

## Ubuntu и локальная сеть — проверено 2026-11-05

Ветка `codex/ubuntu-lan-deployment`, создана от `codex/player-loading-previews`.
`sudo bash scripts/bootstrap.sh` автоматически выбирает подключённый частный IPv4,
согласует bind/origin и публикует только Nginx. Отдельная nftables-таблица до Docker
DNAT допускает к приложению только источники из подключённой подсети; systemd
применяет её перед Docker после reboot. SSH, UFW и чужие таблицы не меняются.
`--lan-ip` задаёт назначенный адрес явно; `--no-lan` пропускает сетевое управление.

На Ubuntu 22.04.5 ВМ501 прошли чистая установка одной командой, повтор и реальная
перезагрузка: 4 healthy, сайт/Swagger/readiness по LAN, единственный mapping
`192.168.1.16:8080 → Nginx:8080`. TCP5432/6379/8000 с другого компьютера refused,
TCP22 доступен. Источник вне подсети получает timeout8080 при доступном SSH22;
счётчик DROP подтверждает срабатывание. Маркер правила и порядок filter → Docker
после reboot проверены. Повтор сохраняет все байты .env и PID dockerd.

При двух отказах (ошибка тестового Swagger-probe и потеря table comment в nft)
внешний контроллер восстановил чистый снимок и сверил 610 исходных пакетов и
настройки до следующей попытки. Исправлен probe; маркер перенесён в rule comment.
После успешной третьей попытки восстановлены исходные данные, затем выполнены
upgrade/repeat/reboot: counts и хеши 40 MP4/JPEG, несетевые настройки, demo manifest
сохранены; 14 файлов SSH/UFW/Docker daemon совпали, UFW inactive.

`make check`: **186 unit passed**, Ruff/форматирование/mypy/ShellCheck passed;
`make test`: **98 integration passed** на настоящих PostgreSQL/Nginx/FFmpeg.
117 новых unit включают защитные отказы при чужой конфигурации, удалённом Docker,
подмене Compose env и смене работающего LAN endpoint. Независимое security-ревью
не оставило подтверждённых открытых P0–P3 в просмотренной области.

ВМ работает по `http://192.168.1.16:8080`, источник `192.168.1.0/24`;
оригинальные данные сохранены. Chrome 156 по LAN прошёл регистрацию/канал,
UI-upload → FFmpeg/READY, реальное воспроизведение и seek, лайк/комментарий/
плейлист с reload. Private: два получателя, посторонний/анонимный, все media/
metadata/HTML/списки/HEAD/Range и выборочный отзыв; оставшийся получатель
продолжает просмотр. Ошибок JavaScript 0; desktop/mobile и восемь снимков
проверены визуально. Добавлены четыре обычных QA-аккаунта и два синтетических
видео, результаты — `.artifacts/lan-browser/`. Ход проверок, снимки и ограничения —

  В Chrome дополнительно проверяются реальные действия ползунком мышью,

  жалоб и ролей уже работает. Аудит Python-зависимостей не включает ОС/образы.
- Финальный безопасный архив и приёмка A1–A9 целиком.
