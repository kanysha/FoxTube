# Страницы ошибок — проверка 2026-11-12

Ветка: `codex/error-pages-2026-11-12`, основа — `main`, `3c448d5`.
Задача: заменить технический JSON при просмотре страниц понятными ошибками
в общем стиле сайта, сохранив API и ограничения доступа.

## Результат

Единый HTML-шаблон обрабатывает ошибки маршрутизации, проверки параметров,
авторизации, лимитов, БД и сервера. Страница предлагает главную и поиск,
при 401 также вход. Статусы HTTP, Allow и Retry-After сохраняются.
Пути `/api`, `/media`, `/health`, `/static`, `/internal-media` и `/openapi.json`
сохраняют машинные ответы независимо от Accept. HTML не отражает детали
исключения, введённый адрес, параметры или метаданные недоступного видео.

Обработчики с обращением к синхронной БД выполняются вне event loop.
Ошибка не создаёт сессию; при 500/503 не выполняется повторное чтение сессии.
Заголовки безопасности применяются и к необработанной 500. При ручной
навигации на 404/422 миниплеер продолжает воспроизведение тем же элементом
video; неудачный автоматический переход оставляет текущее видео.

## Границы

- 500/503 воспроизведены инъекцией в unit-тестах, не остановкой БД в браузере.
- Обработчики относятся к приложению. Ошибки самого Nginx и отклонение
  недоверенного Host промежуточным ПО не переводились в новый шаблон.
- Safari/Firefox, физические устройства, повторная Ubuntu-поставка,
  capacity и аварийное восстановление этим этапом не проверялись.
- Рабочие локальная и серверная установки, реальные данные и секреты
  не изменялись. Публикация и развёртывание не выполнялись.
