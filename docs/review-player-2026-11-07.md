# Расширение плеера — 2026-11-07

Статус: изменения реализованы, браузерная приёмка заблокирована окружением.
Отчёт 2026-11-04 относится к исходной версии и не подтверждает новые функции.
Изменения находятся в текущем рабочем дереве; runtime не обновлялся.

## Что обнаружено и изменено

| Было | Изменение |
|---|---|
| Play/pause, seek, mute/volume, fullscreen, buffering и native fallback | Сохранены HTML5 video и существующие защищённые медиа-URL |
| Нет скорости и пользовательских настроек | Скорость 0,25–2×, повтор, localStorage с обработкой отказа/повреждения данных |
| Только K/пробел/стрелки/M/F | J/L ±10 с, цифры 0–9, Home/End, </>, C/T/I, приблизительный шаг 1/30 с на паузе |
| Click по кадру сразу меняет паузу | Задержка 250 мс для различения click/dblclick; dblclick включает fullscreen |
| Первое касание скрытого плеера сразу меняет паузу | Сначала раскрывает controls; двойное касание края перематывает ±10 с |
| Таймер не учитывает взаимодействие с будущим меню | Меню, hover controls, scrubbing и клавиатурный фокус удерживают панель; скрытые controls inert |
| Вкладка всегда останавливает видео при потере видимости | Фоновое воспроизведение сохраняется, включая системный PiP |
| Нет субтитров | Native TextTrack, выбор дорожки, C; локальный WebVTT до 1 МиБ без отправки на сервер |
| Один MP4 | UI показывает настоящую высоту кадра; фиктивных вариантов/Auto нет |

Дополнительно: широкий режим, системный Picture-in-Picture при поддержке API,
предпросмотр времени на шкале и короткий feedback действий. Escape закрывает
настройки с возвратом фокуса; клик снаружи/выход Tab закрывает панель. Если
браузер не даёт менять volume программно, ползунок скрывается; клавиши сообщают
о регулировке кнопками устройства. Поведение на настоящем iOS не проверено.

Настройки `foxtube.player.v1`: громкость, mute, скорость, повтор, широкий режим,
предпочтение субтитров/язык. История, позиции, ID видео, URL, имена и содержимое
локальных файлов не сохраняются. Файл WebVTT действует в текущем документе;
возврат через bfcache сохраняет его, обычный reload — нет. Неверная замена
не удаляет рабочие cues. Автоматические captions поднимаются над controls,
явно заданное положение сохраняется.

Компонент обрабатывает несколько same-origin `<source data-quality="…">`,
сохраняя позицию и желаемое play/pause. `defaultPlaybackRate` и снимок скорости
предотвращают потерю настройки при `video.load()`. Сервер нескольких разрешений
не создаёт. Отдельная тестовая fixture использует два защищённых URL одного
реального H.264: она проверяет смену источника, а не наличие разных разрешений.

источника, а также неизменённый путь `media → media_key/readable → internal

ограниченными. Статический анализ не заменяет runtime матрицу приватности.

В окружении с доступным Docker выполнить `make check`, `make test`, затем
`make test-browser`. В последний включён `tests/browser/player_extended.py`:
реальные media state после действий/reload, VTT cues и отказ неверной замены,
недоступный storage, source reload, touch и размеры 320×740/390×844/844×390.
Проверить отчёт и просмотреть новые снимки desktop/mobile. Отдельно проверить
системный PiP/fullscreen на устройствах: headless Chrome и эмуляция viewport
не доказывают работу физического iOS/Android/Safari/Firefox.

Системный PiP не гарантирует отображение субтитров и не является внутрисайтовым
плавающим миниплеером. Точный покадровый декодер, автоматические субтитры,
серверное хранение дорожек, новые разрешения и ABR/HLS не добавлялись.
