# Roadmap FoxTube

Актуальная последовательность по TestTask.md и упрощённой архитектуре.
Исторический FoxTube.md не определяет стек: PostgreSQL вместо Redis/Celery,
один MP4 вместо HLS. Доказательства выполнения — в [status.md](status.md).

Обновлено 2026-11-11 после полного аудита текущей ветки. Этапы 1–6 реализованы;
критерии поставки A1–A9 пройдены в окружении Ubuntu 22.04/Chrome. Подробная
матрица, профиль нагрузки и границы доказательств — в
[аудите](review-audit-2026-11-11.md). Производственный SLA и другие платформы
этой приёмкой не подтверждаются.

Чистая Ubuntu 22.04.5 одной командой, автоматические порты/сервисы/firewall,
демо, повтор и reboot проверены заново:
[протокол](review-infrastructure-2026-11-11.md). Ubuntu 24.04 отдельно не проверялась.
Профиль 500 МиБ/две загрузки/кодирование/десять HTTP-зрителей прошёл на ВМ
4 CPU/8 ГБ; измерены ресурсы и задержки. Генератор находился на той же ВМ.
Для производственной оценки остаются отдельный генератор, внешний сетевой
канал и подходящий реальным файлам длительный профиль; smoke не задаёт SLA.
Физические устройства, другие браузеры и публичная HTTPS-поставка отдельно.

По явному запросу пользователя 2026-11-04 PLAYER-01 выполняется в отдельной
ветке перед оставшейся приёмкой поставки. HTML5 video остаётся рабочей основой: пользовательский интерфейс управления не меняет формат MP4,
раздачу Range, права доступа или серверный видеоконвейер.
