# Roadmap FoxTube

Актуальная последовательность по TestTask.md и упрощённой архитектуре.
Исторический FoxTube.md не определяет стек: PostgreSQL вместо Redis/Celery,
один MP4 вместо HLS. Доказательства выполнения — в [status.md](status.md).

Обновлено 2026-11-04 после повторной сверки кода и тестов. Этапы 1–3 дают
работающую видеовертикаль; этап 4 добавил канал и навигацию. Полная приёмка ТЗ ещё не пройдена. Подробная матрица —
в [отчёте](review-2026-11-04.md).

| Этап | Результат и условие завершения | Состояние |
|---|---|---|
| 1. Каркас и инфраструктура | Четыре сервиса, миграции, /docs, health, постоянные тома, повторный bootstrap | Реализован; установка на чистую Ubuntu остаётся финальной проверкой |
| 2. Учётные записи | Регистрация, вход/выход, сессии, канал при регистрации, CSRF и ограничения | Реализован; управление ролями — этап 6 |
| 3. Видеоконвейер | Потоковая загрузка → задания PostgreSQL → FFmpeg → защищённый MP4/превью → HTML5; приватный доступ, реальное воспроизведение и перемотка | Функционально реализован и проверен в Docker; аварийные прогоны и нагрузка остаются этапу 7 |
| 4. Основные экраны | Страница канала и навигация; состояния ленты, поиска, студии и просмотра | Канал/API/ACL реализованы и проверены; финальный браузерный прогон вместе с этапами 5–6 |
| 5. Взаимодействия | Лайки, комментарии, подписки, плейлисты; ACL до выдачи и подсчёта; полный сценарий регистрации → загрузки → просмотра → лайка/комментария | В работе; управление приватным доступом уже реализовано |
| 6. Модерация и роли | Жалобы, скрытие/восстановление, назначение ролей, защита последнего admin и аудит; повторная проверка сбоев и приватности | Запланирован; техническое восстановление видеозаданий сделано на этапе 3 |
| 7. Приёмка и поставка | Демо-наполнение, --demo, A1–A9, нагрузка на целевой конфигурации, чистая Ubuntu одной командой, повторный запуск, README/docs и безопасный архив | Запланирован |
| После этапа 7: стилизованный плеер | Собственные доступные элементы управления поверх HTML5 video; логотип FoxTube на центральном Play | Отдельная желаемая задача [PLAYER-01](tasks/styled-player.md) |

Перед завершением этапа 7 остаются обязательные проверки: принудительная остановка
worker и потеря БД при активном FFmpeg, удаление при активном кодировании,
сохранность опубликованного MP4 после рестарта всего стека, отдельный тест усечённого
результата, память API при входе 500 МиБ, нагрузка 4 CPU/8 ГБ, загрузка через
Swagger Try it out и установка из финальной поставки на чистую Ubuntu 24.04.
Состояния заданий, проверенные сейчас, не заменяют эти прогоны.

PLAYER-01 выполняется после основного roadmap. Текущий нативный плеер остаётся
рабочей основой: пользовательский интерфейс управления не меняет формат MP4,
раздачу Range, права доступа или серверный видеоконвейер.
