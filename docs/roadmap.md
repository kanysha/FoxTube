# Roadmap FoxTube

Актуальная последовательность по TestTask.md и упрощённой архитектуре.
Исторический FoxTube.md не определяет стек: PostgreSQL вместо Redis/Celery,
один MP4 вместо HLS. Доказательства выполнения — в [status.md](status.md).

Обновлено 2026-11-04 после комплексного тестирования. Этапы 1–6
реализованы; этап 7 выполнен частично. Полная приёмка поставки ещё не пройдена.
Подробная матрица и границы проверок — в
[отчёте](review-comprehensive-2026-11-04.md).

| Этап | Результат и условие завершения | Состояние |
|---|---|---|
| 1. Каркас и инфраструктура | Четыре сервиса, миграции, /docs, health, постоянные тома, повторный bootstrap | Реализован; чистая Ubuntu 22.04.5, повторный bootstrap и перезагрузка ВМ passed |
| 2. Учётные записи | Регистрация, вход/выход, сессии, канал при регистрации, CSRF и ограничения | Реализован; управление ролями добавлено на этапе 6 |
| 3. Видеоконвейер | Потоковая загрузка → задания PostgreSQL → FFmpeg → защищённый MP4/превью → HTML5; приватный доступ, реальное воспроизведение и перемотка | Проверен в Docker, включая SIGKILL/потерю БД/удаление при FFmpeg, рестарт и усечённый результат; целевая нагрузка остаётся этапу 7 |
| 4. Основные экраны | Страница канала и навигация; состояния ленты, поиска, студии и просмотра | Реализован; API/ACL и объединённые проверки — в текущем отчёте |

| 6. Модерация и роли | Жалобы, скрытие/восстановление, назначение ролей, защита последнего admin и аудит; повторная проверка приватности | Реализован; конкурентные смены ролей, ограничения SQL, приватность и атомарный аудит проверены |

Приёмка и поставка | Демо-наполнение, --demo, A1–A9, нагрузка на целевой конфигурации, чистая Ubuntu одной командой, повторный запуск, README/docs и безопасный архив | Частично: полный E2E, private с двумя получателями/отзывом, Swagger, аварии, локальная нагрузка 500 МиБ/10 HTTP-зрителей и повторный bootstrap --demo из тестового архива прошли; чистая Ubuntu 22.04.5 с Chrome/private/повтором/перезагрузкой также прошла; нагрузка на 4 CPU/8 ГБ и финальная поставка остаются |

Перед завершением этапа 7 остаются нагрузка на выделенных 4 CPU/8 ГБ и установка
из финальной поставки. Чистая Ubuntu 22.04.5 одной командой проверена:
[протокол](review-ubuntu-2026-11-04.md); 24.04 отдельно не проверялась. Локальная нагрузка
Docker Desktop не подтверждает ёмкость выделенного сервера.

PLAYER-01 выполняется после основного roadmap. Текущий нативный плеер остаётся
рабочей основой: пользовательский интерфейс управления не меняет формат MP4,
раздачу Range, права доступа или серверный видеоконвейер.
