## Архитектура, данные и безопасность

Сохраняется модульный монолит: FastAPI/SQLAlchemy/PostgreSQL, Jinja2/vanilla JS,
нативный HTML5 video, четыре постоянных сервиса. API и worker используют общий
образ; PostgreSQL хранит очередь, постоянный файловый том — медиа. Мягкая
навигация миниплеера получает готовый серверный HTML; отдельного SPA, брокера,
HLS или сервиса рекомендаций нет. HTTP-маршруты используют общие сервисы и ACL.

Проверены модель, пять миграций, FK/unique/check, агрегаты, пагинация после ACL,
идемпотентность social-операций, конкуренция квот, аренды и смен ролей. Долгие
загрузка/FFmpeg/раздача не удерживают транзакцию; синхронные операции выполняются
в подходящих обработчиках/threadpool. Worker публикует только результат текущей
попытки и не меняет приватность/модерацию.

Независимое [security-ревью](review-security-2026-11-11.md) охватывает сессии,
Origin/CSRF, объектные права, приватные GET/HEAD/Range/preview, социальные и
staff-операции, недоверенный ввод/FFmpeg, клиентскую навигацию и конфигурацию.
Подтверждённых открытых P0–P3 после исправления nft ownership нет. Точные Python
зависимости из frozen lock: 29 runtime и 66 development packages, известных
advisory в pip-audit — 0. Это не скан всех системных пакетов и bundled Swagger UI.
Секреты, демо-пароли, рабочие медиа и артефакты исключены из Git и образа.
