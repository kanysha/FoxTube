# UI и рекомендации — 2026-11-10

Ветка `codex/ui-recommendations-2026-11-10`. Изменения продолжают миниплеер,
сохраняют FastAPI/Jinja2/vanilla JS и четыре постоянных сервиса.

## Изменения

- Обновлены светлые фоны, карточки, формы и пустые состояния. Вход и регистрация
  получили отдельную композицию, локальную SVG-иллюстрацию, иконки полей,
  показ/скрытие пароля с клавиатуры и понятный фокус. Автозаполнение сохранено.
- Выбор бокового меню на компьютере сохраняется при reload и обоих видах
  навигации. Мобильная панель закрывается отдельно и не перезаписывает выбор.
  При отказе localStorage работает состояние в памяти.
- На watch добавлена выдача похожих роликов: совпадения слов названия/описания,
  тот же автор, затем новизна. Это подбор по содержимому, без персональной истории.
  API и HTML используют один SQL-сервис с фильтром доступа до LIMIT.
- После настоящего окончания ролика появляется пятисекундный отсчёт, кнопки
  отмены и немедленного просмотра. Настройка autoplay сохраняется локально,
  изначально включена. Следующий ролик в миниплеере не заменяет открытую страницу.
  Громкость/mute и скорость переносятся, WebVTT остаются у своего видео.
- При отказе браузера запускать со звуком применяется прежний muted fallback
  с явным включением звука. Ошибка сети или отозванный доступ останавливают
  автопереход. Скрытие вкладки отменяет отсчёт; возврат сам его не возобновляет.

## Безопасность

Независимое ревью подтвердило фильтрацию текущего, private без разрешения,
hidden/non-READY/deleted и отсутствие привилегии просмотра у moderator/admin.
После отсчёта перепроверяются сессия, исходный и следующий ролики; поздний ответ
не отменяет решение пользователя. Семь сценариев Node VM на фактическом JS
прошли: переход и его блокировка после отмены, отключения, смены сессии,
скрытия вкладки, ручного перехода и закрытия.

До приёмки исправлен обнаруженный дефект шаблона: `dict.items` вместо ключа
`['items']` ломал watch. Подтверждённых незакрытых замечаний в просмотренной
области ревью нет. Полная гарантия безопасности из этого не следует.

## Границы

Физические iOS/Android, Safari/Firefox, публичный HTTPS и отдельная нагрузочная
приёмка не входят в этот прогон. Рекомендации не используют ML, категории
или историю зрителя; при отсутствии совпадений показываются свежие доступные
видео. Продолжение после полной перезагрузки не предусмотрено: браузер создаёт
новый документ. Схема БД, зависимости и правила доступа не изменены.
