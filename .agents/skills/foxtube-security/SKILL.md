# Проверка безопасности FoxTube

Прочитай [security.md](../../../docs/security.md). В режиме ревью не редактируй файлы.
Если поручено исправление, внеси только назначенное исправление и регрессионную проверку.

1. Определи затронутые входы, доверенные компоненты и роль атакующего. Проследи реальный путь до SQL/файла/subprocess; не делай вывод по названию middleware.
2. Сверь объектные права и матрицу ролей. Приватные объекты проверь также через список, поиск, счётчики, комментарии, превью, HEAD и Range.
3. Для мутации проверь CSRF/Origin, владельца, запрещённые поля и конкурирующий запрос. Для сессии — создание, ротацию, срок/отзыв и cookie.
4. Для файла проверь реальные байты/тип, границы пути, сетевые протоколы, секреты в окружении и ресурсный бюджет. Для worker — stale lease, удаление/скрытие во время обработки и атомарность публикации.
5. Воспроизведи подозрение безопасно в выделенной тестовой среде либо подкрепи точным статическим путём. Внешние цели и реальные приватные файлы не использовать.
6. Выдай подтверждённые замечания: P0-P3, файл/строка, вход/условие, последствия, минимальное исправление и проверка регрессии. Гипотезы и непроверенные поверхности перечисли отдельно.

Не превращай ревью в список общих рекомендаций и новых сервисов. Если дефектов
не обнаружено, укажи границы анализа. Недоступная проверка не является успешной.
