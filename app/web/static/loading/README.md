# Индикаторы FoxTube

SVG и статичные PNG скопированы из предоставленного пользователем
`foxtube-loading-kit.zip` (2026-11-04). Геометрия и анимации сохранены.
Исполняемый компонент и демонстрационные страницы из архива не подключаются.

Орбита — переход между страницами и отправка файла; пульс — обработка видео
и ожидание запросов; буфер — ожидание данных в плеере.
Завершение определяется реальным состоянием запроса/видео. Процент показывается
только для переданных байтов файла. При сокращении движения используется PNG.
